# 0.8.0 縮小・鎖19個・重金属音・血のテスト版

0.7.0は正常動作との報告を受けています。0.8.0では全体と当たり判定を75％に縮小し、
鎖を5個追加して19個にしました。追加分にも同じ物理・接触処理を使います。
鉄球に重い金属の衝突音と、鉄球・棘・曲面紋章に沿う標準の武器血メッシュを追加。
暗い素材、凹凸、重い動きは引き継ぎます。Vortexに直接導入できるZIPです。
Windowsビルドと自動テストはゲーム内検証とは別です。この版の追加機能は実機確認が必要です。

## 必要環境

- Skyrim VR 1.4.15.0、SKSEVR 2.0.12。
- HIGGS 1.6.0以降のinterface001。敵の物理衝突と戦闘処理にはPLANCKが必要。
- 使用中のHIGGS/PLANCKが要求する前提MODも導入してください。
- 同梱するのは本MODのファイルのみです。前提MODは同梱しません。

## Vortexで導入

1. 前のChainMorningstarVRを無効にし、ZIPをVortexの「ファイルからインストール」で選択する。
2. MODを有効にして配置し、プラグイン `ChainMorningstarVR.esp` を有効にする。
3. SKSEVRから起動する。エオルンドから購入するか、コンソールで
   `help "Chain Morningstar" 4` を実行して表示されたWEAPのFormIDを確認し、
   `player.additem <表示されたFormID> 1` で取得する。
4. 右手または左手の片方に装備する。同時に2本の使用は未対応。

ZIP直下のESP、SKSE、meshes、texturesがDataへ配置される構成です。
手動のxEdit編集は不要です。ダメージ44、重量17、価値550の片手メイスです。

## 今回接続した処理

- 全体75％、鎖19個。柄42cm、球の半径12cm、棘先まで18cm（VRIK等の倍率適用前）。
- 鎖の中心間隔約4.846cm。75％サイズの14個版より追加5個で約24.23cm延長。
- 19個すべての鎖が壁・床・物体・NPC剛体に沿って曲がる。鎖の攻撃力はゼロ。
- 鉄球の実形状15凸包によるHIGGS接触、低反発と摩擦、12kg設定を維持。
- 衝突時は標準の重金属音。鎖音とは別に再生し、静止中の小さな接触は鳴らさない。
- 鉄球・棘・紋章と同じ表面形状の血メッシュをゲームの流血表示で出す。
  鎖や壁への接触から独自の流血を作らない。標準の血設定・置換テクスチャに従う。
- 実際の敵の頭の剛体へ接触した場合、装備中の頭防具を3分の1で落とす。
- 実際の装備武器の剛体、または読み取り可能な武器メッシュと鉄球の接触を
  確認した場合、その手の武器を3分の1で落とす。
- 接触中の連続コールバックでは再抽選しない。3回ごとに必ず発動する効果ではない。
- 強化・付呪を持つ実物を落とす。プレイヤー、仲間、クエスト保護アイテムは対象外。

## 残る制限と確認項目

鎖は相手の衝突形状に反応して曲がる片方向の処理です。鎖から物体やNPCを押す力は
加えません。輪の穴を埋めたカプセル近似を使い、リンク同士の衝突や物体へ巻き付けて
固定する拘束はありません。手を壁の中へ入れるなど、鎖の長さと接触が両立しない場合は
接触側を優先するため伸びることがあります。
GPUにしか頂点がない武器、スキン変形する武器など、実形状を安全に読めない武器への
メッシュ判定は省略します。HIGGS・PLANCKとの戦闘処理、非常に速い振り、
衝突形状の実機位置合わせは未検証です。通常プレイ用と別のプロファイル／セーブで確認してください。

確認は次の順で行うと原因を絞れます。

1. 装備して抜刀し、75％の大きさ、鎖19個、柄の追従を確認する。
2. 鉄球側の追加した鎖も机の縁・壁・敵の腕へ当て、曲がり、離すと解除されるか確認する。
3. 鎖だけを敵へ触れさせ、体力低下や装備落下がないか確認する。
4. 鉄球を床・壁・物体・敵へ当て、重い金属音を確認する。静止した床接触で連打しないこと。
5. 敵への命中で流血した後、球・棘・紋章の血が表面に沿い、振っても球に追従するか確認する。
6. 血のない新品を壁に当て、血が出ないことを確認する。流血オフ設定なら血は表示されない。
7. 敵の頭と装備武器で従来の3分の1の装備落下を確認する。
8. 装備解除・持ち替え・メニュー・ロード・セル移動後、追従や音が異常にならないか確認する。

ゲーム終了後に別添の `Collect_CMS_Logs.cmd` を実行するとログをまとめられます。
`ChainMorningstarVR.log` の `CMS frame callback alive`、`acquired`、
`Native head prepared` と `Native head attached` が
接続の目印です。これらのログだけでは戦闘の動作確認完了にはなりません。
`Chain collision queries active` と `chainSweeps` / `chainContacts` は鎖の照会と
接触検出の目印です。見た目の位置合わせや体力変化は実機で確認してください。
HIGGS APIが利用できない場合は物理接続できず、警告をログへ記録します。

## 開発者向け

`Source/SKSE/PluginSkeleton` の `vr-physics-test` プリセットを使用します。
`Tools/package_visual_test.py` は互換性のため名称を維持していますが、0.8.0では
物理テストZIPを作成します。同一コミットのWindows DLLとNIF/DDS、ESP生成証拠、
ソースと成果物のハッシュ、実際の衝突凸包とCPU判定平面の一致を検証します。
旧 `CMS_ENABLE_NATIVE_MELEE_PROXY=1` は引き続きコンパイルエラーです。
