# チェーンドモーニングスター 1.0.0-rc1

Vortexで導入できる完成候補です。0.9.0について正常動作の報告を受けています。
今回のログでも鉄球の物理接続と自分の人体への鎖接触を確認しました。
この版では、装備解除と入力読み取りが重なった際の掴み状態の競合を修正し、
掴めなかった理由を記録します。外観・寸法・重さ・衝突音は0.9.0から維持します。
正式版の全実機確認を終えたものではありません。確認内容はFINAL_CHECK_JA.txtにあります。

## 必要環境

- Skyrim VR 1.4.15.0、SKSEVR 2.0.12。
- HIGGS 1.6.0以降のinterface001、PLANCKとそれぞれの前提MOD。
- 自分の人体への鎖衝突にはVRIKが必要です。
- 前提MODはこのZIPに含まれていません。

受領した0.9.0ログではHIGGS build=1101000、PLANCK build=80100、
VRIKのSKSE登録値=00000870でした。この記録だけで他の組み合わせの互換性は保証しません。

## Vortexで導入・更新

1. Skyrim VRを終了する。更新前のセーブを残す。
2. 以前のChainMorningstarVRをVortexで無効にする。
3. ChainMorningstarVR-1.0.0-rc1.zipを「ファイルからインストール」で選択する。
4. MODを有効にして配置し、ChainMorningstarVR.espも有効にする。
5. SKSEVRから起動する。以前の同名DLL・NIF・テクスチャが競合していないか確認する。

ZIP直下のESP、SKSE、meshes、texturesがDataへ配置される構成です。
手動のxEdit編集は不要です。0.9.0と同じESP・フォームIDを使うため、
持っている武器を削除・再取得する必要はありません。更新時はいったん納刀してください。
戻す場合はゲームを終了して本版を無効にし、保管した旧版を有効にします。
MODを完全に削除して通常プレイを続ける場合は、導入前のセーブを使用してください。

## 入手と操作

エオルンドから購入できます。コンソールでは player.additem XX000800 1。
XXはVortexで確認したChainMorningstarVR.espのロード順（16進2桁）です。
表示名は「チェーンドモーニングスター」。片手メイス、攻撃44・重量17・価値550です。

右手または左手の片方に1本を装備して抜刀します。同時に2本の使用は未対応です。
右手に装備したときは、左手の武器・盾・魔法・掴んだ物を外し、鉄球へ近づけて
左グリップを押し続けると保持します。先に押してから近づける操作では保持しません。
離すと放します。両手を鎖の長さ以上に広げたときや追跡が飛んだときも解除します。
掴み直すには一度グリップを離します。保持中も床・壁との接触を優先します。

HIGGSの掴み・引き寄せ・両手持ち中や、他MODが手を無効にしている間は保持しません。
HIGGSが自分の武器を両手持ち候補にした状態でも拒否される可能性があります。
現行の公開APIではこの状態と引き寄せ待ち等を区別できないため、未解決の互換性項目として
残しています。掴めない場合は空手を鉄球から離し、ボタンを離してから再試行し、ログを収集してください。

## 武器の動作

- 承認済みモデルの75％サイズ、鎖19個。追加5個にも同じ物理・接触処理を使用。
- 黒い鉄、凹凸のある木、使い込まれた革、球面に沿った紋章を維持。
- 鉄球は12kgの設定、低反発と減衰。大型金属音と控えめな金属打撃音を重ねます。
- 鎖は壁・床・物体・NPC・自分のVRIK身体へ接触して曲がります。鎖の攻撃力はゼロ。
- ゲーム側で流血が生じたとき、球・棘・紋章の表面に沿う武器血メッシュを表示。
- 敵の頭へ実接触した場合は頭装備、装備中の武器へ実接触した場合はその武器を
  各独立接触で3分の1の確率で落とす処理を実装しています。
- 同じ接触中は再抽選しません。3回ごとに必ず発動する効果ではありません。
  頭装備のない敵、仲間、プレイヤー、保護されたクエスト装備は対象外です。

## 制限と確認状況

鎖の当たり判定は輪の穴を埋めたカプセル近似です。鎖から相手を押す力、リンク同士の
衝突、巻き付けて固定する拘束はありません。人体は骨に追従する11カプセルで近似し、
服・鎧の表面と完全には一致しません。長さと接触が両立しない場合、鎖が伸びることがあります。
安全に実形状を読めない武器のメッシュ判定は省略します。

今回までのログには左手で保持した行と、装備落下で生成された物の記録がありません。
未記録は失敗の証明でも動作完了の証明でもありません。長時間戦闘、売買と在庫更新、
xEdit Check for Errorsなども含め、RELEASE_STATUS.mdに正式版の残る確認を記載しています。

## ログを送る場合

ゲーム終了後、別添のChainMorningstarVR-1.0.0-rc1-feedback-tools.zipを解凍し、
Collect_CMS_Logs.cmdを実行します。できたCMS-feedback-日時.zipを添付してください。
runtime_summary.jsonには実際に読み込まれた版、掴みの成立・拒否理由、
装備落下の記録を集計します。イベントは一部のみ記録されるため、全発生回数ではありません。
