チェーンドモーニングスター 1.0.0-audit3 実機診断版

保持中の勝手な回転、約90度の回転切替、床接触時の不安定な動きを修正した版です。
左トリガー（人差し指）で掴みます。側面グリップの操作は従来どおりです。
実機での安定性の確認はこれからです。

【Vortexで入れ替え】
1. Skyrim VRを終了し、Vortexで前のChainMorningstarVRを無効にします。
2. ChainMorningstarVR-1.0.0-audit3-diagnostic.zipを「ファイルからインストール」で導入します。
3. 今回のMODとChainMorningstarVR.espを有効にして配置します。本体一式入りです。
   同名DLLの競合がある場合はaudit3を優先します。
4. HIGGS・PLANCK・VRIKを有効にしたまま、いつもどおりSKSEVRで起動します。

【今回の確認：約3分】
1. 右手に装備し、左手は武器・盾・魔法・ほかの物を持たない状態にします。
   左トリガーを離したまま鉄球へ手のひらを近づけ、少し止めてから押し続けます。
2. 鉄球を少し持ち上げて鎖をたるませ、両手を10秒止めます。
   鉄球が勝手にずれたり回ったりしないか確認します。
3. 保持したまま左手首をゆっくり回します。模様とトゲが手に合わせて回るか確認します。
   左手を止めて右手だけゆっくり動かしたとき、鉄球が勝手に回らないかも確認します。
4. 鉄球を床のすぐ上で放します。床に軽く触れた際に激しく跳ねないか、
   そのまま10秒置いて振動・回転を続けないか確認します。机や壁でも軽く当てます。
5. 放す・掴み直す操作を3回行い、通常の振りで重い動きと衝突音が残っているか確認します。
6. 納刀・抜刀し、普通の剣へ持ち替えたときにHIGGSの通常操作が使えるか確認します。

【結果を送る】
1. 確認後にゲームを終了します。ログ収集前には再起動しないでください。
2. 別添のChainMorningstarVR-1.0.0-audit3-feedback-tools.zipを展開します。
   ログ収集用ZIPはVortexへ入れません。
3. Collect_CMS_Logs.cmdをダブルクリックし、できたCMS-feedback-日時.zipを添付してください。
4. 「保持中」「床へ接触」「放した直後」のどこで異常が残ったかを教えてください。
   残る場合は、その動きが見える短い動画があると照合に役立ちます。

runtime_summary.jsonのcms_versionが1.0.0-audit3なら今回のDLLです。
姿勢復元のログは競合を補正した記録であり、その数だけで失敗・成功とは判定しません。
設定変更や大量の再試行は不要です。問題が残る場合はその状態でログを送ってください。

戻す場合はゲームを終了し、Vortexでaudit3を無効にして前の版を有効に戻し、配置します。
Skyrim VR 1.4.15.0 / SKSEVR 2.0.12。HIGGS 1.6.0以降・PLANCKが必要です。
鎖の自分の人体との衝突にはVRIKが必要です。前提MODは同梱しません。
