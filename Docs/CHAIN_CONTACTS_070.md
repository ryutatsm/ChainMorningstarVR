# 0.7.0 鎖接触・重量感・黒鉄仕上げ

2026-10-06。作業ブランチ `astra/zero-base-audit-v050`。mainへのマージではありません。
ユーザーは0.6.1で手への追従と鉄球の動作を確認済み。今回の追加機能の実機確認は未実施です。

## 鎖の接触

14リンクを個別のカプセルとして、90Hzの固定更新ごとにHavokへ照会します。
未接触時は14照会、接触時は最大2巡の28照会。リンク中心の前位置から予測位置まで
線形キャストし、姿勢変更分は端点の移動距離で半径を保守的に膨らませます。
静止時にも近接点照会を行い、動く物体からの接触を拾います。

外半径47.4mm、カプセル中心線の半長23.4mmを武器モデルの表示スケールで拡縮。
描画と同じリンク軸を使い、回転後の支持距離で接触面を投影します。
接触面と鎖の距離制約を交互に解き、内向き速度を打ち消し、限定した摩擦を加えます。
復帰補正自体で鎖が跳ねないよう、侵入していた前位置も補正します。
鉄球の遅延接触で鎖位置を補正する際にも、その補正前からの掃引を維持します。
接触面は各更新で取り直し、障害物を離れた後に永続する平面を残しません。

鎖用の剛体・リスナーをゲーム世界へ登録せず、NPCや物体へインパルスも与えません。
`NativeContactRouter`、装備落下抽選、PLANCKの攻撃剛体には接続していません。
敵との接触はPLANCKの実際の身体剛体を対象とし、プレイヤー自身、同じ衝突グループ、
鉄球、トリガー、水、キャラクターコントローラーの補助形状を除外します。

制限は片方向の接触応答、輪の穴を埋める近似、リンク相互衝突なし、物体を巻いて
固定する拘束なしです。速い物体が鎖を完全に通過した場合の物体側の連続掃引と、
障害物を回り込む経路探索は行いません。手が壁に入り長さと接触が矛盾すると、接触優先で伸び得ます。

## ネイティブ境界の根拠

- Skyrim VR 1.4.15.0限定。既存の初期化時バージョン検査を通過した場合だけ実行。
- CommonLibSSE-NG 3.5.2、commit `67ba410068022e06ebf42cfca44274b0aa98a2da` の
  `hkpCapsuleShape` / `hkpCollidable` / `hkpCollisionInput` / collectorレイアウト。
- カプセルのvtableはCommonLibの `VTABLE_hkpCapsuleShape[0]` を使用。
  所有する一時ABI記述子（0x50、16byte整列）のみを設定し、サイズと配置を静的検査。
  クエリ中だけ有効で、エンジンが保持・破棄するオブジェクトにはしない。
- HIGGS commit `93bf67b1bc4c4a11a20ccaef0d5012781d0d7eee` の
  `include/RE/offsets.h` / `src/RE/offsets.cpp`: LinearCast `0xAB5EC0`、
  GetClosestPoints `0xAB62D0`、GetRefFromCollidable `0x3B4940`。
- 接続済みのHIGGS鉄球と同じ衝突フィルター情報を照会に使い、鉄球が衝突する壁・床・
  PLANCK剛体を対象とする。ピッキング専用レイヤーの対象範囲には依存しない。
  フィルターの値を借りるだけで剛体や接触イベントを登録しないため、鎖の攻撃は発生しない。
  HIGGSの共有ピッキング球は書き換えず、独立した一時collidableとtransformを使う。
- 世界の読み取りロックを保持し、HIGGS本体・世代・装備・shapeの所有を既存の経路で確認。
  フレーム停止、解除、持ち替え、ロード、テレポートでは古い掃引を使わない。

## 重量感と色

計算上の鉄球質量8→12kg、鉄球の90Hz減衰係数0.995→0.990、反発0.08→0.025、
接触摩擦0.28→0.38。距離制約は80→96反復。重力9.80665m/s²と手の実位置は維持。
NIFの落下時質量・反発・減衰も調整。ゲームの所持重量は17のままです。
重量感はシミュレーション上の挙動であり、コントローラーへ実際の重さを加える機能ではありません。

拡散色は鉄球0.60、木0.72、革0.64、紐0.68、棘0.66、鎖0.62、金具0.66、紋章0.70倍。
金属の明るい擦れには最大0.08の補正を残し、反射の強さも下げます。
法線・スペキュラーマスク・環境マスクは暗色化前の画像から生成し、凹凸を保持。
紋章の形状生成にも暗色化前の専用入力を渡すため、曲面・浮き彫り・UVは変わりません。

## 検証範囲

- 中ほどの鎖への壁・角接触、速い掃引、動く支持面、0.85倍スケール、不正サンプルの除外。
- 接触面の解除、停止・テレポート・装備解除時に照会しないこと、鉄球復帰前からの掃引。
- 45/72/80/90/120/144Hzでの鎖接触、既存の鉄球接触・装備落下・所有権の回帰テスト。
- 手を35cm動かして止める比較では、3〜4秒目の鉄球速度二乗の積算が旧設定の約0.226倍。
  これはテスト軌道上の数値で、ゲームで感じる重さの保証ではありません。
- NIFの27メッシュと17ノードの形状・UV・法線・変換を0.6.1成果物と比較。
- 色の輝度・細部相関、DXT5の全mipmap、凹凸と紋章形状の保持を確認。

実機では机の縁、壁の角、敵の腕に鎖だけを当て、曲がりと解除、体力非減少、
装備非落下、フレーム時間、重量感、同じ照明での材質を確認してください。
ログには `Chain collision queries active` と累計 `chainSweeps` / `chainContacts` を出します。
