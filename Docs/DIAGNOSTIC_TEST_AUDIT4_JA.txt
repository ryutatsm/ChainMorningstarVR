チェーンドモーニングスター 1.0.0-audit4 装備落下の実機確認版

鉄球が敵の頭・手に当たると、接触1回につき3分の1の確率で対応する装備1個が落ちます。
頭は兜・帽子・サークレット、手はその手に持つ武器・盾が対象です。
武器・盾そのものへの接触も対象です。篭手・手袋、胴装備は対象ではありません。
鎖だけの接触にはこの効果はありません。3回当てれば必ず落ちる仕組みではありません。

【Vortexで入れ替え】
1. Skyrim VRを終了し、更新前のセーブを残します。
2. Vortexで前のChainMorningstarVRを無効にします。
3. ChainMorningstarVR-1.0.0-audit4-diagnostic.zipを「ファイルからインストール」で導入します。
4. 今回のMODとChainMorningstarVR.espを有効にして配置します。本体一式入りです。
   同名DLLの競合がある場合はaudit4を優先します。武器の再取得は不要です。
5. HIGGS・PLANCK・VRIKを有効にしたまま、いつもどおりSKSEVRで起動します。

【今回の確認】
1. テスト用のセーブで、兜を着け、武器や盾を構えている敵を選びます。
   町の非敵対NPCや仲間は対象ではありません。頭装備のない敵でも確認できません。
2. まず頭へ鉄球を当て、頭装備が外れて地面へ落ちるか確認します。
   外れない場合は、鉄球をいったん十分離してから、数回の独立した接触を試します。
3. 別の敵またはテスト前のセーブで、右手・右手武器、左手・盾をそれぞれ試します。
   当たった手の武器・盾が落ち、反対の手の片手武器や篭手が外れないか確認します。
   両手剣・両手斧・戦鎚・弓では、左右の手が同じ1個の武器を指します。
4. 鉄球を触れたままにしても抽選が連打されないこと、胴・前腕だけに触れた際は
   頭装備や手の武器が外れないことを確認します。
5. 落ちた装備を拾えるか確認します。強化・付呪された装備なら、その状態も確認します。
6. 左トリガーで鉄球を保持して放す操作を一度確認し、以前の安定した動作が続くか見ます。

死亡時のゲーム本来の武器落下と区別するため、生きている間の落下を優先して見てください。
敵が先に死んだ場合や装備がすでに外れた場合は、同じ相手を何度も叩く必要はありません。
クエスト装備、取り外せない装備、正確な装備個体を特定できない場合は対象外です。
特殊な種族・MOD武器では部位の物理ボディや表面データを取得できず、対象外になる場合があります。

【結果を送る】
1. 確認後にゲームを終了します。ログ収集前には再起動しないでください。
2. 別添のChainMorningstarVR-1.0.0-audit4-feedback-tools.zipを展開します。
   ログ収集用ZIPはVortexへ入れません。
3. Collect_CMS_Logs.cmdをダブルクリックし、できたCMS-feedback-日時.zipを添付してください。
4. 「頭」「右手の武器」「左手の武器・盾」のどれが落ちたか、または落ちなかったかを教えてください。
   相手の装備が見える短い動画があれば、部位判定と照合できます。

runtime_summary.jsonのcms_versionが1.0.0-audit4なら今回のDLLです。
ログでは命中部位・対象装備・抽選結果・実際の落下オブジェクトを分けて記録します。
抽選ゼロは確率の失敗を意味しません。敵対状態や対象装備の判定から調べます。
自動テストとWindowsビルドでは実際のゲーム内落下までは確認できないため、今回は実機確認版です。

戻す場合はゲームを終了し、Vortexでaudit4を無効にして前の版を有効に戻し、配置します。
Skyrim VR 1.4.15.0 / SKSEVR 2.0.12。HIGGS 1.6.0以降・PLANCKが必要です。
鎖の自分の人体との衝突にはVRIKが必要です。前提MODは同梱しません。
